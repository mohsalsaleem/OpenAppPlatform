The second release candidate of OAP's agent-native rewrite. It's for testing
the release itself, ahead of v0.2.0: its full notes, getting-started guide
and agents guide come with v0.2.0.

## Changes since rc.1

- `oapctl host install` lets the server pull the released oapd even when
  this machine has a copy of it. Before, a machine that had pulled the
  image (for its own architecture) shipped that copy and refused to install
  on a server of another architecture.

## Install

```sh
curl -fsSL https://raw.githubusercontent.com/mohsalsaleem/OpenAppPlatform/rewrite-phase-4/install.sh | OAP_VERSION=v0.2.0-rc.2 sh
```

`install.sh` installs `oapctl` only if it matches this release's
`SHA256SUMS`. `oapctl host install` pulls the oapd image named in
`oapd-image.txt`, pinned by digest.

## What it has

- Onboarding from a server's address and root password: a read-only check,
  approved fixes, install (oapd and Caddy in Docker), an owner key, and a
  hand-off that removes OAP's SSH access. Uninstall puts the server back.
- One API for agents (observe, propose, apply, await, watch, explain, ask)
  over Connect, gRPC, JSON, MCP and the CLI, with a briefing and the
  app-authoring skill served by the server.
- Scoped agents with device login, a policy envelope with risk tiers and
  change facts, approvals through asks, pause and revoke.
- Deploys without dropped requests, scaling, rollback, migrations as jobs,
  and secrets the owner sets that agents never see.
- Out-of-process extensions with grants and memory caps: builders and
  GitHub change facts.
