# v0.1 Supported Baseline Acceptance

Review scope: the supported M0 workflow plus M1.1–M1.6 **minimal baseline**.
This review does not certify every broader M1 ambition or production readiness.
No M2–M6 feature is advanced as a release prerequisite. Candidate notes are
[here](releases/v0.1.md).

## Reproducible Gate

Run `make test-local` from a clean Docker-capable checkout before committing and
pushing. The harness snapshots Git-visible source, starts fresh PostgreSQL and an
isolated Docker Engine, builds the shipping image, and removes its fixtures on exit.
No Coolify credentials or host workload socket are supplied to that harness.
See [local testing](local-testing.md) for pins, expected external-suite skips,
reports and the exact-source pre-push check. Git CI remains disabled.

## Explicit Deferrals

No zero-downtime SLA, general domains/ACME, full image architecture/provenance
policy, scanning/signing, automatic cleanup/retention, key rotation, notification
sending, AI diagnosis, indexed log backend or agent direct database access is
included. The lightweight definition and 10-app/50-component resource benchmark
remain roadmap work; no RSS/CPU budget compliance is claimed. These are disclosed
limits of the preview, not silently completed roadmap requirements.

The deliverable is a verified release candidate. Publishing a tag/release and
production promotion are separate from this review. Keep existing workloads,
private backups and key copies intact throughout acceptance.
